# Data Visualization with Matplotlib and Seaborn

This folder contains Python projects and exercises focused on **data visualization** using Matplotlib and Seaborn libraries.

## Topics Covered
- Creating line, bar, and scatter plots
- Histograms and boxplots
- Customizing plots: titles, labels, colors, legends
- Subplots and figure layouts
- Seaborn visualizations: heatmaps, pairplots, regression plots
- Practical visualization examples on real datasets

## Purpose
These projects are designed to strengthen Python programming skills and provide hands-on experience in presenting data visually. Data visualization is a critical skill in data analysis and helps communicate insights effectively.

## How to Run
1. Make sure Python, Matplotlib, and Seaborn are installed.
2. Open the Jupyter notebook or Python script in this folder.
3. Run each cell or script to see the visualizations.
